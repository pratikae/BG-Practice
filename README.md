# Bhagavad Gita Practice

A web app for memorizing Bhagavad Gita shlokas by chanting. Pick a chapter, choose to play just the odd or even verses, and the app plays the other half aloud while leaving a pause — timed to match the length of the skipped verse — for you to chant it from memory yourself. All 18 chapters are included.

Disclaimer: Speeding up will result in a higher pitch, use at your discretion. 

Live at [pratikae.github.io/BG-Practice](https://pratikae.github.io/BG-Practice/).
